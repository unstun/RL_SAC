# V18 — V16-C 本地复训（R3）

## 版本性质

**零代码改动，零参数改动。** 纯复训实验（V16-C 配置第三次训练）。

## 背景

- V16-C ep190（远端训练）是当前最优：short 0.85/14.43m, long 1.00/46.00m (runs=20)
- V17 R1/R2 复训均失败（long SR 最高 0.8），详见 `docs/versions/v17/`
- V18 = 第三次复训（R3），本地 GPU (RTX 3070 Ti)

## 训练配置（与 V16-C 完全相同）

| 参数 | 值 |
|------|-----|
| `reward_k_len` | 0.10 |
| `reward_k_p` | 12.0 |
| `forest_adm_horizon` | 45 |
| `eps_decay` | 100 |
| `episodes` | 300 |
| `--dueling --mha` | 启用 |

## 最佳结果（ep240, runs=20, seed=77）

| 套件 | CNN-DDQN SR | CNN-DDQN path | A*-MPC SR | A*-MPC path |
|------|-------------|---------------|-----------|-------------|
| short | 0.85 | 15.34m | 1.00 | 14.20m |
| long | 1.00 | 48.17m | 1.00 | 42.98m |

## 对比 V16-C ep190 (runs=20)

| 指标 | V18 ep240 | V16-C ep190 | 差异 |
|------|-----------|-------------|------|
| short SR | 0.85 | 0.85 | 持平 |
| short path | 15.34m | 14.43m | +6.3% |
| long SR | 1.00 | 1.00 | 持平 |
| long path | 48.17m | 46.00m | +4.7% |

## 结论

- R3 成功复现 V16-C 核心性能（双套件 long SR=1.00）
- 路径长度略差于 V16-C ep190（short +6.3%, long +4.7%）
- §13 门槛仍未通过（short SR=0.85 < A* 1.0, 所有 path > A*）
- V16-C ep190（远端）仍为全局最优模型
