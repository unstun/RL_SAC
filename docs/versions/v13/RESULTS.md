## 分析

### 非单调行为

Horizon 缩短并非单调改善：H25/H20 比 H30 全面恶化，H15 反而最优。
推测原因：H25/H20 处于"不上不下"区间 — 掩码既不够严格保证安全，也不够宽松让 Q 网络自由学习。

### H15 的矛盾

- short SR=1.0 且 inad_rate=10.7%（最佳），但 long SR 仅 0.4
- Long 场景需要更多步决策，宽松掩码增加累积错误概率

### H10 的启示

- 成功时路径最短（15.40m < A\*-MPC 16.87m）且时间最快（9.57s < 10.0s）
- 证明**掩码确实是路径过长的根因**
- 但 SR 过低（0.6/0.2），训练量不足以学会无掩码保护下的安全行为

## 门槛检查

无配置通过 CLAUDE.md §13 全部三条门槛（SR/路径/时间同时优于 A\*-MPC）。

## 结论

1. Horizon 参数调优无法同时兼顾 SR 和路径长度
2. H30 仍为综合最优配置（SR=0.95/0.95）
3. H10 证明了方向正确：若能提高短 horizon 下的 SR，则路径长度可超越 A\*-MPC
4. 下一步需结构性改进（动态 horizon / 连续动作空间 / 更多训练量）
