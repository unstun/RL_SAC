# v9p5 — 航向对齐奖励 + 增加训练量

## 版本定位

- 基线：v9p2（SR=95%/95%，当前最佳）
- 核心改动：新增航向对齐奖励 `r_heading = k_h · cos(α_goal)` + episodes 300→500
- 目标：降低曲率、缩短路径，同时不损失成功率

## 方法

在每步奖励中叠加航向对齐项：
- `reward += k_heading * cos(alpha_goal)`
- `k_heading = 0.3`（保守初始值）
- `cos(α) = 1.0` 正对目标 → +0.3；`cos(α) = -1.0` 背对 → -0.3

纯局部信息，不依赖外部规划器（区别于 v9p3/v9p4 的 Dijkstra 方案）。

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `forest_reward_k_heading` | 0.3 | 航向对齐系数 |
| `episodes` | 500 | 训练量（v9p2=300） |
| 其他奖励参数 | 同 v9p2 | k_t=0.15, k_len=0.02, k_delta=0.8 |
