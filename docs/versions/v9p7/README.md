# v9p7 — k_len / k_t 消融实验

## 目标

v9p2 在 long 场景表现差（path+6.7%，time+21.3%，方差极大），且参数甜蜜点极窄。
本版本通过消融实验诊断 k_len 和 k_t 的独立贡献，寻找更稳定的参数方向。

## 基准对比

| 版本 | k_len | k_t | Short SR | Short Path | Long SR | Long Path |
|------|-------|-----|----------|------------|---------|-----------|
| v7p1（无惩罚）| 0.0 | 0.0 | 95% | 15.77m | 100% | 42.93m |
| v9p2（当前最佳）| 0.02 | 0.15 | 95% | 15.50m | 95% | 45.82m |

## 消融实验设计

| 实验名 | k_len | k_t | 假设 |
|--------|-------|-----|------|
| klen | 0.02 | 0.0 | 只路径惩罚 |
| kt10 | 0.0 | 0.10 | 只时间惩罚（保守值） |
| kt15 | 0.0 | 0.15 | 只时间惩罚（全量） |
| small | 0.01 | 0.08 | 保守组合 |

## 执行参数

- profile: v7p1, episodes: 150, seed: 21, device: cuda
- smoke: runs=3（short/mid/long）
