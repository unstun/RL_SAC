## 消融结论

1. **k_len 是 mid/long 崩溃的主因**：klen 组（k_len=0.02, k_t=0.0）mid/long SR 全为 0%，
   说明 v9p2 的 long 场景高方差根源在于 k_len 惩罚扰乱了 mid/long 路径的奖励结构。

2. **k_t=0.10 最稳健**：kt10 在 short/mid/long 三场景 SR 均为 67%，
   路径未比 v9p2 更短，但方向最有希望（三场景都能跑通）。

3. **k_t=0.15 单独用效果差**：path 大幅增加（short 18.74m vs baseline 17.03m），
   time 极差（20s），说明 v9p2 里 k_t=0.15 能凑效是因为 k_len 形成了某种抵消。

4. **保守组合（small）不如 v9p2**：mid/long 崩溃，没有优势。

## 下一步（扫参方向）

基于消融结论，推荐扫参方向：只使用 k_t（k_len=0.0），细扫 k_t 值寻找 SR=100% 且路径短的甜蜜点。
候选：k_t = 0.06, 0.08, 0.12（kt10=0.10 的附近区域）。
