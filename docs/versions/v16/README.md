# V16 — H × k_p 消融实验（k_len=0.10 + 长视距掩码）

## 版本定位

在 V15 (k_len=0.05) 基础上，测试更激进的路径惩罚 k_len=0.10，
配合不同视距 H∈{30,45} 和进度奖励系数 k_p∈{12,24}。

**零代码改动。** 所有改进通过 CLI 参数实现。

## 核心发现

1. **H45 远优于 H30**: H45 实验均达到 long SR=1.0，H30 实验 long SR≤0.8
2. **k_p=12 优于 k_p=24**: k_p=12 的 short path 更短（14.43m vs 17.28m）
3. **最优配置 = H45 + k_p=12 + k_len=0.10 (实验 C, ep190)**
