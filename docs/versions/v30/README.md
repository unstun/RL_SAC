# V30 — 观测栅格分辨率消融（obs_map_size）

## 版本摘要

对全局地图下采样分辨率进行消融实验：N=16 和 N=24
（当前 baseline N=12）。测试更高分辨率的全局占据图
是否能帮助 agent 区分绕障路径方向，从而缩短 long path。

## 方法

**核心思路**：N=12 时全局地图压到 12×12，每格覆盖约 8m×8m，
树簇细节糊在一起，agent 无法区分"绕左"还是"绕右"哪条更短。
提高分辨率到 N=16/24，理论上能看清绕路通道。

**零代码改动**：`--obs-map-size` CLI flag 已存在，网络自动推断布局。

## 消融矩阵

| 实验 | N | obs_dim | 参数量 | 状态 |
|------|---|---------|--------|------|
| A (baseline) | 12 | 154 | 0.41M | V22-D formal 已知 |
| B | 16 | 266 | ~0.52M | smoke 完成 |
| C | 24 | 586 | ~0.84M | smoke 完成 |

## 主要结果（smoke runs=3，negotiate K=10）

| 配置 | short SR | short path | long SR | long path |
|------|----------|------------|---------|-----------|
| N=12 V22-D (formal) | 0.95 | 15.75m | 1.00 | **46.11m** |
| N=16 B (smoke) | 0.667 | 13.18m | 1.00 | **65.22m** |
| N=24 C (smoke) | 0.667 | 13.37m | 0.667 | 51.82m |
| A*-MPC (formal) | 0.95 | 15.77m | 1.00 | 42.93m |

## 结论

**负面结果。** N=16 long path=65.22m（82 个路径拐角，agent 绕圈），
N=24 long path=51.82m，均劣于 N=12 V22-D 46.11m。

根因：更大观测空间需要更多训练才能收敛，300ep 远不够。
N=12 的 V22-D 经历多轮超参调优，单次 300ep 的 N=16/24 无法与之竞争。
