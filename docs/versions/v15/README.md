# v15 — 路径长度优化（Epsilon 调度修复 + Reward Shaping + 推理门控放松）

## 概述

在 v11 最优配置（CNN-DDQN + Dueling + MHA）基础上，针对路径长度差距
（long path +10% vs A\*-MPC）进行三方面优化：

1. **Epsilon 调度修复**：`eps_decay` 4500→100，修复训练全程 ε≈0.19 的错配
2. **Reward Shaping**：`reward_k_len` 0.02→0.05，路径惩罚 2.5 倍增强
3. **推理门控放松**：`min_progress_m` 0.01→0.0，消除推理时进度门控

## 改动性质

**纯配置实验，零代码改动。** 所有改进通过 CLI 参数实现。

## 最佳配置

| 参数 | v11 值 | v15 值 | 说明 |
|------|--------|--------|------|
| `eps_decay` | 4500 | 100 | ep100 时 ε=0.02，进入利用阶段 |
| `episodes` | 150 | 300 | 更多利用阶段训练（实际 ep130 早停） |
| `reward_k_len` | 0.02 | 0.05 | 路径惩罚 2.5x |
| `min_progress_m`(推理) | 0.01 | 0.0 | 禁用进度门控 |
| seed | 21 | 21 | 训练种子 |

## 关键教训

1. **训练高度依赖 seed**：seed=21 好, seed=42 完全失败, seed=7 部分成功
2. **"best" checkpoint 不可靠**：训练选出的 best ckpt 推理效果常劣于中段 ckpt
3. **k_len=0.10 过于激进**：SR 崩溃至 0.2，k_len=0.05 是甜点值
4. **进度门控 prog=0.0 一致有效**：所有实验中 long SR 提升 +0.1~0.2
